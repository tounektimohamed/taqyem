## 📖 Overview

**Taqyem** is a complete evaluation & assessment management platform developed with Flutter and Firebase. It streamlines result tracking and provides a polished multi-platform mobile experience.

## ✨ Features

- Evaluation & results management
- Offline-ready data flows
- Multi-platform mobile support
- Clean, responsive UI


## 🛠 Tech Stack

Flutter, Dart, Firebase.

## 🚀 Getting Started

```bash
git clone <repo-url>
cd <repo>
flutter pub get
flutter run
```

> Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel).
